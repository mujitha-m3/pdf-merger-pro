# 📄 PDF Merger Pro

A free online tool to merge PDF files instantly. Streamlit-powered web app with freemium pricing model.

## 🌟 Features

- ✅ **Free Tier**: Merge up to 5 PDF files per operation
- 🎯 **Premium Tier**: Merge up to 100 PDF files, unlimited features
- 🔒 **Secure**: Files are processed in-memory and deleted immediately
- 📱 **Responsive**: Works on desktop, tablet, and mobile
- ⚡ **Fast**: PDF merging in seconds
- 💯 **No Installation**: Use directly in your browser

## 📋 Requirements

- Python 3.8+
- Streamlit
- PyPDF2

## 🚀 Local Setup & Testing

1. **Clone or download this project**

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Run locally**:
   ```bash
   streamlit run app.py
   ```

4. **Open in browser**: `http://localhost:8501`

## 🌐 Deploy to Internet (Free)

### Option 1: Streamlit Cloud (Easiest & Free) ⭐ RECOMMENDED

1. **Push code to GitHub**:
   - Create a GitHub account (free)
   - Create a new repository
   - Push this code to the repository

2. **Deploy on Streamlit Cloud**:
   - Go to https://share.streamlit.io
   - Sign in with GitHub
   - Click "New app"
   - Select your repository and `app.py` file
   - Click "Deploy"
   - Get your public URL instantly!

3. **Your app will be live at**: `https://your-username-app-name.streamlit.app`

**Pros**: Free, automatic updates (just push to GitHub), no server management

**Cons**: Limited (1GB RAM, 1 worker thread), sleeps after 1 hour of inactivity on free tier

### Option 2: Render (Free Alternative)

1. **Create an account** at https://render.com

2. **Create `render.yaml`** in your project root:
   ```yaml
   services:
     - type: web
       name: pdf-merger-pro
       env: python
       region: oregon
       plan: free
       startCommand: "streamlit run app.py --server.port=${PORT}"
   ```

3. **Push to GitHub and deploy** via Render dashboard

4. **Your app URL**: https://your-app-name.onrender.com

**Pros**: Free tier, more reliable than Streamlit Cloud

**Cons**: Spins down after 15 minutes of inactivity

## 🐛 Troubleshooting

### App won't load on Streamlit Cloud
- Check `requirements.txt` has all dependencies
- Verify `app.py` is in root directory
- Check Python version compatibility

### Files too large to merge
- Add size check: `if file.size > 50_000_000: st.error("File too large")`
- Show file size to user

### Premium key not working
- Verify key exactly matches in `VALID_PREMIUM_KEYS`
- Check for spaces or typos
